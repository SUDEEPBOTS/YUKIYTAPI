# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Yuki YT API, please report it privately:
- Contact: https://t.me/SUDEEPBOTS
- Email: security@sudeepbots.org

Never report security issues through public GitHub issues.
