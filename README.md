# YUKI YT API 🚀

Welcome to the **YUKI YT API**, a powerful, high-performance, and secure API for downloading media.

## 🛠️ Installation

To install and start the API server on your VPS, run the following command (One-Click Install):

```bash
curl -fsSL https://install.yukiapi.site/install.sh | bash
```

## 📜 Features
- **High Performance:** Powered by FastAPI & Uvicorn.
- **Highly Secure:** Core logic is strictly protected and packed into C-level binaries using PyArmor.
- **Cross-Platform:** Universal runtime supports Linux (Ubuntu, Debian, etc.), Windows, and macOS architectures.
- **Easy Setup:** Fully automated environment, dependency installation, and process management.
